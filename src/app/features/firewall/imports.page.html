Import a firewall log

  1. Open the router at http://192.168.100.1 and go to the firewall log page.
  2. Make sure the log is enabled for the directions you care about. Logging every direction can slow forwarding.
  3. Use “Download Log File” and upload the file here (.log or .txt, plain text).
